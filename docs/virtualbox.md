# Подготовка Ubuntu в VirtualBox

ВМ используется для проверки и не является обязательной зависимостью установки: эксперты могут использовать любую выделенную Ubuntu 24.04 amd64.

## Автоматическая установка из Windows

Требуются VirtualBox 7.2, PowerShell 7, OpenSSH Client и интернет. Согласованный компактный стенд: 4 ГБ RAM, 4 vCPU, динамический диск 30 ГБ. При наличии свободной памяти можно указать `-MemoryMB 8192` для запаса.

```powershell
New-Item -ItemType Directory -Force .local
curl.exe -fL --retry 3 -o .local/ubuntu-24.04.4-live-server-amd64.iso https://releases.ubuntu.com/24.04/ubuntu-24.04.4-live-server-amd64.iso
./tools/create-vm.ps1 -Start
```

Сценарий проверяет SHA256 ISO по опубликованной Ubuntu сумме, создаёт отдельный SSH-ключ и случайный пароль только в исключённой папке `.local`. Пользователь ВМ `mts` получает sudo без пароля для автоматизации выделенного тестового стенда; SSH принимает только ключ. NAT-порты привязаны к localhost Windows, а не ко всем сетевым интерфейсам.

Установка занимает время; проверяйте завершение через SSH:

```powershell
ssh -i .local/vm_ed25519 -p 2222 mts@127.0.0.1 'cloud-init status --wait; cat /etc/os-release; sudo -n true'
```

При первом соединении сравните SSH-отпечаток с консолью ВМ. После завершения выключите ВМ (`sudo poweroff`), отсоедините установочные DVD через VirtualBox и сделайте снимок `clean-ubuntu` перед запуском Kubernetes. Затем включите ВМ.

Если ВМ уже зарегистрирована, сценарий сохраняет её и не перезаписывает диски. Прерывание создания требует осмотра существующей ВМ; автоматического удаления нет.

## Ручной вариант

Создайте Ubuntu 24.04 amd64 с указанными ресурсами. Включите SSH, настройте доступ пользователя с sudo. Для NAT добавьте перенаправления `127.0.0.1:2222 → 22` и `127.0.0.1:8080 → 30080`. Скопируйте или клонируйте проект в Ubuntu, затем выполните инструкции README.

## Ограничения

ВМ, ISO, вспомогательные файлы автоматической установки и приватные ключи находятся в `.local/`. Эта папка не входит в Git. Пароль ВМ не нужно передавать экспертам: они создают собственную среду и учётные данные.
