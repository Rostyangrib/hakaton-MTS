## Текущая задача

Стенд развернут. verify.sh завершился с кодом 0; HTTP также проверен из Windows через http://127.0.0.1:8080/. Далее проверяется повторная установка и восстановление.

Решение остаётся компактным: одна ВМ, только компоненты ТЗ и необходимые проверки.

## Ограничения

- Пользователь согласовал компактный стенд с 4 ГБ RAM, 4 vCPU и 30 ГБ диска из-за доступной памяти компьютера.
- Первый функциональный запуск подтверждён; установка с чистого снимка и повторный запуск ещё не проверены.
- Одноузловая архитектура не обеспечивает доступность при отказе ВМ.

## Следующий шаг

Повторная установка, восстановление Pod, перезагрузка и повторение с чистого снимка.
