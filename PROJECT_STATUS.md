## Текущая задача

2026-10-03: добавлены CI и автоматическая проверка HTTP-кодов/latency. Расширенный verify прошёл на ВМ: 2xx 3 → 16, 4xx 0 → 1, измерения latency 8 → 25, среднее 1,81 мс. README содержит краткий отчёт проверок. Ожидаются результат CI в GitHub и обновление паспорта/архива.

Реализация завершена. Подтверждены повторные bootstrap/deploy, восстановление удалённого Pod и перезагрузка ВМ. Полная установка из clean-ubuntu прошла без ручных исправлений: HTTP 200, targets UP, счётчик 23 → 40, обе записи access/error доставлены. Метрики HTTP-кодов и latency проверены отдельно. Дата проверки: 2026-10-02.

Решение остаётся компактным: одна ВМ, только компоненты ТЗ и необходимые проверки.

## Ограничения

- Пользователь согласовал компактный стенд с 4 ГБ RAM, 4 vCPU и 30 ГБ диска из-за доступной памяти компьютера.
- Установка зависит от внешних репозиториев и registry; история Prometheus временная.
- Одноузловая архитектура не обеспечивает доступность при отказе ВМ.
